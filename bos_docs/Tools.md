# Tools

The Tools section brings together the main utilities used to inspect performance, memory behavior, and on-chip communication. Tracy Performance Profiler helps analyze execution timing and kernel-level activity across host and device code. L1 Buffer Visualizer focuses on memory usage and buffer state during model execution. NOC Visualizer helps trace Network-on-Chip traffic and identify data-movement bottlenecks. Together, these tools support profiling, debugging, and optimization across the BOS software stack.
