# NOC Visualizer

The NOC (Network-on-Chip) Visualizer is a tool for analyzing and debugging data movement patterns across the Eagle-N interconnect. Visualize NOC traffic, identify bottlenecks, optimize data routing, and understand comprehensive hardware communication for model execution.
