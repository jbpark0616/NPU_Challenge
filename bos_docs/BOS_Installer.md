# BOS Installer

## Upcoming Feature[](#upcoming-feature)

The BOS Installer is an in-progress guided setup tool designed to simplify the process of running BOS models. Planned capabilities include:

- Host environment preparation
- Device firmware setup and flashing
- Runtime and toolchain installation

Once released, the BOS Installer will reduce manual setup steps and provide a streamlined path from initial setup to first model execution.

## Availability[](#availability)

Detailed documentation and commands for BOS installer will be published in a future update.
