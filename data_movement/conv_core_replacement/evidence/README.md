# Validation Evidence

This directory contains compact evidence that is useful in Git.

- `full_model_pytest_pass.xml` records one passing guarded BOS ResNet50
  full-model remapping test.

Large profiler outputs remain local in `../conv_core_validated_latency/` and
`../profiler_raw/`; both are excluded from Git. Their final extracted values and
figures are preserved in `../policy/figures/` and the policy documentation.
