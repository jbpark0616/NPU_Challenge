| `equations/` | Editable MILP equations and equation-rendering assets |
| `발표_전체대본_15분.md` | Current Korean presentation script |

Final result plots are generated and maintained with the experiment that owns
them:

- [`../data_movement/conv_core_replacement/policy/figures/`](../data_movement/conv_core_replacement/policy/figures/)
- [`../study_note/aging_simulation/plots/`](../study_note/aging_simulation/plots/)

traceable, while this directory holds only presentation composition assets.
